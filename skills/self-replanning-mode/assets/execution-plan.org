* How to use this plan

Work in this loop:

1. Understand the problem.
2. Make the plan.
3. Carry it out, checking each step.
4. Reconstruct all unfinished work from the evidence, validate it, and continue.

- Change a task with =C-c C-t=.
- Set a priority with =C-c C-x p=.
- Set a date with =C-c C-s=.
- Filter by tags with =C-c \=.
- Fill in =OWNER= when taking a task.
- Check =DEPENDS= before moving a task to NEXT.
- If an approach keeps failing, stop and revise the remaining plan.
- Fill in =Feedback:= at every phase check.
- Fill in =Replan:= after reconsidering every unfinished phase and task.
- Do not finish a phase before its check passes.
