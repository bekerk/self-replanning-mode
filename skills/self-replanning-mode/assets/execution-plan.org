* How to use this plan

Work in this loop:

1. Understand the problem.
2. Make the plan.
3. Carry it out with the smallest useful checks.
4. Reconstruct all unfinished work from the evidence, validate it, and continue.

- Change a task with =C-c C-t=.
- Set a priority with =C-c C-x p=.
- Set a date with =C-c C-s=.
- Filter by tags with =C-c \=.
- Fill in =OWNER= when taking a task.
- Check =DEPENDS= before moving a task to NEXT.
- If an approach keeps failing, stop and revise the remaining plan.
- Write =Expected:= in each phase check while it is still a prediction.
- Fill in =Feedback:= at every phase check, comparing against =Expected=.
- Fill in =Replan:=; match its depth to the gap between =Expected= and what
  happened.
- Remove Phase 2 and make Final check depend on Phase 1 check when Phase 1
  proves the whole goal.
- Do not finish a phase before its check passes.
